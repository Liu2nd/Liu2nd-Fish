Liu2nd_Fish v0.2.0 — 非开发者使用指南
=======================================

A. 立即预览广告外观（无需安装任何开发工具）
双击本文件夹里的「Liu2nd_Fish_双击预览.html」。
可调整弹窗外观、大小、替换背景图，并尝试在中间加载网址。
注意：此为普通浏览器内打开的 HTML 预览版，有些视频网站会禁止 iframe 加载；它不能代表最终 EXE 的全部功能。

B. 真正 Windows 免安装版（不需要 Python/Node/微软商店）
本 ZIP 里是可交给 Codex 开发的源码，**不含已经编译好的 EXE**。
为保证你自己的电脑完全不需要开发工具，可以通过 GitHub Actions 在云端编译：
1. 在 github.com/new 新建空仓库，名称：Liu2nd_Fish。
2. 将解压后本文件夹中的文件和文件夹上传仓库根目录，注意不要只上传 ZIP 本身。
3. 打开 Actions → 制作 Liu2nd_Fish 免安装软件 → Run workflow → windows-x64。
4. 任务显示成功后，到本次任务的 Artifacts 下载 Liu2nd_Fish-Windows-x64。
5. 解压，双击其中的 Windows-x64-Portable.exe。

C. 如何操作正式 EXE
输入网址回车，中间区域是可操作的真实网页；顶部绿色空白处拖动窗口；
主窗口右下角调大小；⚙ 调整网页位置/大小及广告皮肤；Alt+Q 隐藏/恢复；
托盘右键可真正退出。自动保存设置。所有个人数据只保存在本机。

E. 在 EXE 里修改（不需要任何开发工具）
1. 点击主弹窗顶部绿色工具条中的 ⚙，即可打开设置窗口。
2. 在设置里输入网址，点击「打开网页」；中间的网页会随之更新。
3. 导入新的 PNG/JPG/WebP 广告背景图，拖动绿色矩形调整中间真实网页的大小和位置。
4. 直接修改弹窗宽高、透明度、置顶、静音。
5. 快捷键：点击输入框直接按组合键即可保存，Esc 取消，默认/停用按钮分别用于恢复或解绑。
   默认键：Alt+Q 显示/隐藏；Alt+M 网页静音；Ctrl+Alt+S 打开设置。
   如果系统或其他软件占用了快捷键，会提示失败，不覆盖之前的设置。
6. 这些修改保存在系统用户数据目录，不需要修改源代码，也不需要重新编译 EXE。


D. 兼容性与限制
目标 Win10 64位、Win11 64位（优先 Win10 LTSC 1809）；Win10 32位、ARM64、macOS、Linux 可单独构建。
当前版本已通过源码静态检查与单元测试，但未完成各操作系统和视频网站的 EXE 实机测试。
某些网站的登录/视频播放可能受 DRM、网站政策或浏览器环境限制；不绕过安全限制。
