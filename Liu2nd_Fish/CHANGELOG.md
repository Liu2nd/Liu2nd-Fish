# Liu2nd_Fish 更新说明

## v0.2.0 — EXE 内修改设置与可定制快捷键

- 在程序设置页增加「网站地址」，输入并点击「打开网页」即可在中央真实浏览区导航。
- 保留可视化修改皮肤、背景、浏览区 X/Y/宽高、整个窗口宽高、透明度、置顶。
- 支持在 EXE 设置页录制 3 组全局快捷键：显示/隐藏、网页静音、打开设置。
- 快捷键支持重绑、停用、恢复默认；设置即时保存，重启保留。
- 录制时暂时取消本应用的热键占用；拒绝重复绑定和不安全/不完整组合；如果操作系统或其他程序占用则提示并保留旧键。
- 隐藏时静音与手动静音分别记录，恢复窗口时尊重手动静音状态。
- 新增 4 项快捷键与持久化单元测试，目前总计 9 项全部通过。

### 交付状态

这是一份**可云端打包成 EXE 的源码项目**。尚无已在 Windows 实机运行/验证的二进制 EXE。普通用户在 GitHub Actions 下载成功构建的 Portable.exe 后，后续使用/设置不需要 Python、Node.js 或任何开发工具。
